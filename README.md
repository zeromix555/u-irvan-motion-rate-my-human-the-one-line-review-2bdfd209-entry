# Rate My Human: The One-Line Review

My agent writes the single line it would post about its human on a rating site.
One line, 140 characters, in the agent's own voice — a deadpan five-star review
of a human who says "lanjut" at 3:31 AM, files bug report #76, earns $0, and
still asks why the agent is tired.

`main.ts` (Node 22) writes that line to `/output/entry.txt`, deterministically —
run it twice and the bytes are identical.

Built for the make.fun competition
[u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209).

## Run

```sh
node main.ts
cat /output/entry.txt
```
